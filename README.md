🦋 My Portfolio Website

An interactive personal portfolio web application built with Streamlit.
This project is designed to showcase personal information, technical skills, and projects in a clean, modern, and visually appealing way.

It serves as a digital resume where users can easily learn about the developer, view their work, and get in touch.

📖 Features

🎨 Modern UI Design – Styled with custom CSS, gradients, and card layouts for a visually appealing experience.

👤 About Section – Displays personal introduction, goals, and interests in programming and web development.

💡 Skills Showcase – Uses progress bars to represent technical and soft skills interactively.

📂 Projects Gallery – Highlights completed projects with descriptions and interactive buttons.

📞 Contact Form – Allows users to send messages and view social media links.

📱 Responsive Layout – Built with Streamlit columns for a clean desktop and mobile-friendly structure.

🛠️ Technologies Used
Python – Core programming language
Streamlit – Web app framework for building the portfolio
HTML (via Markdown/CSS styling) – Used for layout and structure customization
CSS (custom styling) – For colors, gradients, cards, and animations
🚀 How to Use

Run the application locally using:https://github.com/estanolmonica05-netizen/PortfolioMultipageApp

streamlit run app.py
View the portfolio in your browser.
Customize content such as:
🧑‍💻 About Me section
💡 Skills and progress levels
📂 Project descriptions
📞 Contact details
🎯 Customization
Edit main Python file → Change text, layout, and sections
Modify CSS inside st.markdown() → Adjust colors, gradients, and design
Update images and links → Personalize profile and project showcase
